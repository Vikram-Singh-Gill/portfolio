Summary

Fluffy is an easy-difficulty Windows machine designed around an assumed breach scenario, where credentials for a low-privileged user j.fleischman / J0elTHEM4n1990! are provided. By exploiting CVE-2025-24071, the credentials of another low-privileged user can be obtained. Further enumeration reveals the existence of ACLs over the winrm_svc and ca_svc accounts. WinRM can then be used to log in to the target using the winrc_svc account. Exploitation of an Active Directory Certificate service (ESC16) using the ca_svc account is required to obtain access to the Administrator account.

We see SMB (on port 445 ), LDAP (on port 389 ), and Kerberos (on port 88 ) are running. Hence, we can identify this as a Domain Controller. From the nmap scan results, we see that the domain name is fluffy.htb , and the Domain Controller's DNS name is DC01.fluffy.htb. So I added that to the /etc/hosts file.

$ echo "10.129.232.88 fluffy.htb dc01.fluffy.htb"|sudo tee -a /etc/hosts

Using the provided credentials j.fleischman:J0elTHEM4n1990! , I enumerated the SMB service to see available shares.
